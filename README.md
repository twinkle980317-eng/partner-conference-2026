## 一、项目概览

本次大会由润达联合华为举办。2026年12月18日（周五）全体抵沪并赴润达健康参观交流，19日（周六）在上海虹桥附近酒店举办全天主会、颁奖及答谢晚宴，20日（周日）赴华为练秋湖研发中心参观后，统一乘车前往虹桥枢纽返程。

- 大会总预算 ¥153,353 含酒店、交通、会务及5%不可预见费
- 计划到会 约 80 人 代理商 20–25 家 · 约40人
- 主会地点 [虹桥附近酒店](./hotels.md) 12月19日，会议厅租用1天

| 项目 | 安排 |
| --- | --- |
| 项目名称 | 润达×华为 2026年经销商合作伙伴大会 |
| 主题 | 同心同行 · 智启2027｜AI点亮医疗未来 |

| 场地与住宿 | 虹桥附近酒店待定，主会厅约80座、含 LED 屏，答谢晚宴8桌、每桌10人。住宿暂按25间双床房、18日和19日两晚。 |
| 交通 | 18日按到达指引赴润达健康。19日在酒店开会，无集体出发。20日安排2辆大巴，行李随车，参观后集中送虹桥枢纽。 |

**感谢与表彰。**感谢合作伙伴2026年并肩同行，19日主会结束前为每家到会代理商颁发一项公司奖。

**目标与信心。**讲清2027年产品、销售策略和渠道政策，让代理商带着明确的业务方向、项目方法、宣传工具和跟进联系人回去。

**复盘指标。**代理商到会率≥90%，2027目标确认覆盖≥80%，收集有效需求≥30条，满意度≥4.5/5，会后30天内转发大会素材的代理商≥50%。

## 二、大会主题与整体节奏

已定主题：**同心同行 · 智启2027**，副标题 **AI点亮医疗未来**。主标题讲伙伴关系和来年，副标题讲医疗AI的前景；"点亮"也是共启仪式的核心动作，主视觉、仪式和宣传稿共用一句话。

| 用在哪里 | 写法 |
| --- | --- |
| 主视觉/LED主画面 | 上行大字"同心同行 · 智启2027"，下行小字"AI点亮医疗未来"，底部"润达×华为 2026年经销商合作伙伴大会" |
| 邀请函标题 | 同心同行 · 智启2027｜AI点亮医疗未来 |
| 共启仪式 | 启动后大屏主视觉由暗到亮，最后定格在"AI点亮医疗未来"；主持人结束语："今天，我们一起点亮医疗AI的未来。" |
| 新闻稿标题参考 | 同心同行·智启2027：润达携手华为与伙伴共同点亮医疗AI未来 |
| 英文小字（可选） | Together Forward · AI Lights Up the Future of Healthcare |

- **18日 · 先见面。**抵沪后在润达健康参观展厅、分组破冰，从项目机会和合作卡点里找出次日要解决的问题。
- **19日 · 说清明年的合作。**上午从润达年度回顾出发，经伙伴案例、产品演示和售前交流，衔接到午餐前的华为专题。下午安排销售政策、市场赋能、交付服务和商务支持，并完成答疑、共启与颁奖，最后举行答谢晚宴。
- **20日 · 参观与返程。**上午参观练秋湖并交流，午间由两辆大巴送往虹桥枢纽。

代理商政策和商务协同安排为闭门内容，由润达及代理商参加。一般产品和伙伴交流环节采用短讲、案例与问答相结合。

建议设一名总指挥统筹，下设6个工作组，每组一名明确负责人；华为方设一名固定对接人。姓名待填。

| 工作组 | 负责人 | 主要职责 |
| --- | --- | --- |
| 总指挥 | 待定（润达领导） | 方案、预算、重大决策拍板；与华为高层沟通 |
| 华为对接组 | 待定 | 确认20日练秋湖参观、停车及入园；落实华为唯一专题、嘉宾和品牌审核 |
| 内容组 | 待定 | 三天流程、18日展厅议题、讲者PPT、闭门政策、主持稿与圆桌嘉宾 |
| 嘉宾与伙伴组 | 待定（销售负责人） | 邀请、回执、奖项评选、目标确认书沟通、会后回访 |
| 会务后勤组 | 待定 | 酒店会议厅、住宿及餐饮、19日礼品发放、20日车辆和行李管理 |
| 视觉物料组 | 待定（市场） | 主视觉、LED画面、奖杯证书、易拉宝与指引牌、印刷品 |
| 宣传组 | 待定（市场） | 三波预热、启动视频外包管理、内部剪辑、摄影与云相册直播、获奖海报、会后稿件与代理商素材包 |

工作机制：每周一、周四各开一次30分钟推进会，对照附录推进表逐项核验进度；会前最后一周改为每日站会。

### 主要风险与应对

| 风险 | 影响 | 准备与应对 |
| --- | --- | --- |
| 酒店合同范围或报价变化 | 超酒店预算或产生加项 | 锁定主会租期、LED实际配置与技术支持、午晚餐菜单、放房与退改；确认酒水、服务费及税费。 |
| 住宿实际超过25间或两晚 | 费用偏差、到场接待紧张 | 回执区分单/双住、到离日期；用最终间夜数重算，逐周核销预留。 |
| 主会超时或同厅晚餐换场慢 | 影响颁奖与开席 | 酒店书面确认45分钟是否够；彩排撤台、圆桌及上菜动线。主持人压缩临时分享，保留颁奖和用餐。 |
| 华为专题人员变动 | 单一专题中断 | 确认备讲与备用课件；技术口径由华为对接人提前复核。 |
| 12月20日练秋湖接待或车辆变化 | 无法按09:30入园，影响返程 | 提前确认周日接待、报备、车牌及候车位置；复核导航用时，必要时前移集合。 |
| 行李混放或错过返程 | 物品遗失、错过车次 | 车号对应行李标签与清单；司机候车；到站双向核对。按最终交回时间提醒预留换乘及值机。 |
| 闭门政策外传 | 影响代理商政策执行 | 政策、商务段限定参加人员，暂停录音录像和图片直播，内部材料单独发放。 |
| 奖项或名单变更 | 漏颁、错名 | 按公司唯一标识去重；公司名、奖项、出席代表在锁版前逐项核对，缺席备案补交。 |
| 照片、产品信息或联名未确认 | 外宣返工 | 现场和会后内容按已确认口径发布；闭门、未发布产品和基地限拍区域不纳入公开素材。 |
| 半日交流散焦或问题未跟进 | 次日讨论缺少议题 | 每家公司提交一项机会与一项需求；每条记录责任人与下次反馈时间。 |
| 冬季雨天及交通波动 | 室外候车与游览体验下降 | 准备室内集合点，保持分车群联络；司机提前到场，参观以确认路线为准。 |
